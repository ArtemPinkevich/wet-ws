Вызывай, когда UX Impact Gate или отдельная задача требует разбора состояний, фокуса, восстановления либо визуального решения. Orchestrator может обработать простой случай сам; этот скилл не обязательная стадия и не требует отдельного UX states skill.

Прочитай выбранные истории, согласованное поведение и затронутые решения Context Pack. Не проводи вымышленных интервью и не выдавай экспертный анализ за пользовательский тест. Не добавляй функции вне scope, фиксируй только необходимую дельту в пакете.

## Состояния / восстановление

Для затронутого сценария свяжи наблюдаемое событие с видимым состоянием, доступностью действия, сохранностью ввода и восстановлением. Различай состояние интерфейса и соединений; потерянная связь делает старые данные неизвестными, не актуальными. Укажи disabled/loading/error и переходы, лишь если они затронуты.

Echo ждёт ответ, посредник не требует ответа на каждое сообщение. Не переноси правило одной попытки из echo на поток обмена. Не выдавай send за доставку, не вводи автоматические повторы данных/команд без решения. Учитывай поздние события, очистку при отставшем UI и неизвестный исход команды, когда вопрос их затрагивает. Отсутствие внешнего интернета само по себе не ошибка локального обмена; офлайн не заявляй проверенным без свидетельства.

## Визуальное решение / доступность

SKIP/NO_CHANGE не создаёт mockups, невизуальная delta может остаться в пакете. Визуальное изменение требует только затронутых макетов в docs/engineering/iterations/iteration-NN/mockups/, зеркалящих docs/engineering/ui/mockups/. Не копируй полный набор, не создавай отдельный обязательный UI/UX-документ. Статусы, ссылки и затронутые surfaces/states запиши в пакете; canonical merge и удаление delta выполняются по lifecycle iteration-orchestrator после реализации и приёмки.

Для затронутого экрана проверь порядок фокуса, клавиатурные действия, сохранность фокуса при событиях, подписи и понятное восстановление. Цвет дополнен текстом; фокус заметен, readonly сохраняет чтение/копирование. Длинные строки визуально переносятся без изменения данных, пробелы/переносы сохраняются, HTML показывается как текст. Учитывай браузер и desktop только в затронутом объёме.

Без реализации не заявляй проверку контраста, клавиатуры или доступности: перечисли будущие проверки. Если выполняешь ограниченное задание роли, возвращай спорные решения основному агенту и не редактируй общий журнал.
