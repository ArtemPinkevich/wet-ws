# Дорожная карта продукта

Карта определяет порядок итераций, их цели и состав по [user-stories.md](user-stories.md). Содержание историй хранится только в backlog. Каждая включённая история выполняется целиком в одной итерации. Требования, критерии приёмки, инженерные уточнения и результаты гейтов относятся к материалам конкретной итерации / Iteration Context Pack. Календарные сроки карта не задаёт.

## Итерация 1 — проверка вариантов поставки

**Статус:** завершена.

**Цель:** проверить общую основу серверной и настольной поставок до разработки функций трансивера.

**Истории:** не назначены; итерация проверяет техническую основу поставок. Истории поставки остаются в разделе «Позже».

**Почему здесь:** общая основа нужна для последующих функций в обеих поставках.

**Результат:** подтверждена общая техническая основа браузерной и настольной поставок. Итог и ограничения — в [Context Pack](../engineering/iterations/iteration-01/context-pack.md).

## Итерация 6 — индикация некорректного JSON

**Статус:** DONE, 2026-10-26. Реализация варианта 4 принята владельцем ответом «принято». Implementation Ready, Verification и Conformance (Independent Reviewer) PASS; canonical UI и документация обновлены. Результат и ограничения — в [Context Pack 06](../engineering/iterations/iteration-06/context-pack.md).

**Цель:** замечать синтаксические ошибки JSON непосредственно при редактировании сообщения в рабочей области.

**Единственная история:** [US-025 — Индикация некорректного JSON при редактировании](user-stories.md#us-025--индикация-некорректного-json-при-редактировании).

**Почему здесь:** прямой запрос автора от 2026-10-26; опирается на существующий редактор. До реализации автору предъявляются 3–5 интерактивных вариантов ненавязчивой индикации. Широкая US-015 целиком в итерацию не включена.

**Результат:** режим Text/JSON, ненавязчивый маркер у строки синтаксической ошибки, общий статус и подробности. Проверка не меняет текст и не блокирует отправку/сохранение. US-015 целиком остаётся вне scope.
