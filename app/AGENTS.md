# Работа с приложением

Имена файлов и каталогов приложения задавай латиницей. В схемах структуры перечисляй только имена; пояснения размещай отдельно, чтобы их нельзя было принять за часть пути.

Начни с [README](README.md). Команды npm и Docker выполняй из этого каталога; Git-команды — из родительского корня wet-ws-ai. Исходники находятся в `src`, тесты — в `tests`; перед изменениями исходников прочитай [src/AGENTS.md](src/AGENTS.md).

В общей рабочей области рядом с app находится ../docs, Git-корень — родительский wet-ws-ai. Прочитай ../docs/product/roadmap.md и относящийся к задаче Context Pack. При переносе только каталога app используй постановку задачи и README, уточняй отсутствующий контекст по необходимости. Сборка не должна зависеть от соседних каталогов.

Не копируй соседние документы и внутренние материалы в app. docs ведётся рядом с приложением в общем Git-корне; проектные skills, публичные определения ролей и AGENTS.md входят в исходники; локальные исключения задаёт корневой .gitignore. Не добавляй генерируемые `dist`, `out`, зависимости или переносимые инструменты. Фиксируй в Git исходники, тесты, конфигурацию и lockfile. Не меняй поведение приложения в задаче переноса файлов.

Проверяй изменения подходящими тестами. Создание артефакта, его запуск и реальный обмен — разные результаты; ограничения проверки указывай явно.
