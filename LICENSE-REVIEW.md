SHA-256 исходного файла и LICENSE: `120ae34213c742ce7e844ce534e383c42c900b688b1061e4b2c08e1840ceacf2`. Сведения о правообладателе вынесены в NOTICE, чтобы не менять стандартный текст: Артём Пинкевич (Artem Pinkevich). Юридическое лицо не добавлялось.

В отличие от прежнего проекта, стандартная лицензия **не разрешает распространение**, включая бесплатные форки; отдельного разрешения на все виды личного/некоммерческого использования в ней также нет. Разрешённая цель сформулирована как внутренние бизнес-операции пользователя и его компании. Не следует переносить обещания прежнего проекта о форках, плагинах и персональном использовании в толкование выбранной лицензии. README даёт только краткое пояснение, условия определяет LICENSE. Коммерческая лицензия, платные функции и лицензионные ключи в этой задаче не создавались.

В истории `origin/main` находятся начальный commit `a1a16dc` от Артёма Пинкевича и `673ab41` от `AkaikinMD`. В других имеющихся локальных remote refs есть дальнейший вклад `AkaikinMD`. Авторство коммита само по себе не устанавливает принадлежность исключительных прав или права работодателя.

Для сопоставления использованы все 11 коммитов доступной локальной истории и их 105 уникальных Git blobs, включая 80 blobs кода. Текущий набор приложения — 59 неигнорируемых файлов, в том числе 44 файла кода, разметки и стилей. Проверки полного содержимого файлов, блоков из трёх последовательных содержательных строк (обрезаны краевые пробелы, отброшены строки короче 20 символов) и окон из 40 последовательных токенов кода не выявили совпадений. Lockfile исключён из строкового сравнения. Исходные тексты старой версии — Next.js/React-клиент и Express/TypeScript-сервер; текущее приложение использует иной набор модулей на TypeScript, Node HTTP, ws и Electron.

База проверки воспроизводится через `git rev-list --all`, `git ls-tree -r <commit>`, `git cat-file blob <hash>` и `git ls-files --others --exclude-standard -- app`. SHA-256 отсортированного списка `path + " " + SHA256(file bytes)`, LF после каждой строки: `cc90e5218296edf67fa9d4309c8f682bae742db06757bd17a3c14db37d64e462`. Генерируемые файлы, зависимости и локальные инструменты в собственный код не включены.

**Вывод:** использование прежнего MIT-кода в текущем собственном коде не обнаружено. **Независимость реализации полностью не подтверждена**: история создания текущих файлов отсутствует в доступных коммитах; короткие, переработанные или отсутствующие в локальной истории заимствования могли остаться незамеченными. Подтверждение происхождения и принадлежности прав остаётся за автором; автоматический поиск не является юридическим заключением.

## Решение по LICENSE-MIT

При подтверждённом отсутствии старого MIT-материала исторический LICENSE-MIT не обязателен в новом дереве: старый текст остаётся в истории, доступной по commit `673ab417805741fa2aef08d3256a6191b98ea34c`. Удаление старых client/server или самой копии лицензии не отменяет ранее предоставленных MIT-прав.

Сейчас `LICENSE-MIT` **сохранён консервативно**, поскольку независимость текущей реализации не доказана. Проверка не установила конкретных фрагментов, из-за которых именно этот файл был бы обязателен. Его область — исторический MIT-материал, а не весь новый код. После подтверждения происхождения автор может убрать этот файл и соответствующие ссылки; при обнаружении MIT-заимствований необходимо сохранить применимые полные уведомления и отметить их область. Сохранение одного исторического файла не заменяет такой проверки и не устраняет неопределённость прав.

Ранее полученный MIT-материал продолжает использоваться на условиях MIT, включая разрешённое ею коммерческое использование; выбранная PolyForm не сужает уже выданные права. Код третьих лиц нельзя объявлять исключительно собственным кодом под PolyForm.

## Зависимости и оставшиеся проверки

В `app/package-lock.json` — 217 dependency entries с лицензиями MIT, BSD-2-Clause, BSD-3-Clause, Apache-2.0, ISC, BlueOak-1.0.0 и `(MIT OR CC0-1.0)`. Runtime-зависимость `ws@8.22.0` отмечена MIT. Это метаданные, а не полный юридический аудит пакетов. Сторонние права сохраняются; LICENSE-MIT не заменяет лицензии ws, Electron, Chromium и других компонентов. Перед выпуском ZIP/Docker-артефактов нужно проверить включение обязательных license/NOTICE-файлов; текущая подготовка касается исходников, готовые поставки не публикуются.

До публикации остаются подтверждение прав на текущие файлы и юридическая оценка применимости выбранных условий к предполагаемым сценариям, включая личное использование, подрядчиков и размещение сервиса. Неизменённый стандартный текст сам по себе не подтверждает право лицензировать чужой код.

План публикации сохраняет историю main: новая ветка должна происходить от актуального origin/main в отдельном clone существующего репозитория. Локальный unborn main не используется как основание. История не переписывается, удаление старой структуры предлагается только в новом commit будущего PR. Коммит, push и PR требуют отдельного разрешения и в этой задаче не выполняются.
